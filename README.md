# プログラミングサークルのサイト

ビルドや有料サービスなしで公開できる、HTML/CSS/JavaScriptの静的サイトです。活動内容と掲載記事は `content.js` の配列に追加して更新します。

## 公開前に編集するところ

1. `content.js` の `name` を実際のサークル名にする
2. `instagram` と `x` に公式アカウントのURLを入れる（空欄のSNSはリンク無効表示になります）
3. `activities` のサンプル3件を実際の活動に置き換える
4. `press` に記事を追加する（記事URL・媒体名・掲載日・タイトル）
5. `index.html` のページタイトルと説明文をサークル名に合わせる

## 無料で公開する

Cloudflare Pagesは静的ファイルを無料枠で配信でき、独自ドメインも後から設定できます。GitHubリポジトリを使う方法が更新しやすくおすすめです。

1. GitHubでこのフォルダのファイルを新しい公開リポジトリに追加する
2. Cloudflareのアカウントを作り、Workers & PagesからPagesプロジェクトを作成する
3. GitHubリポジトリを接続する。フレームワークは「None」、ビルドコマンドは空欄、出力ディレクトリは `/`（リポジトリ直下）にする
4. デプロイ後に表示される `*.pages.dev` のURLを共有する

更新は `content.js` やサイトファイルをGitHubに反映するだけで自動デプロイされます。独自ドメインは別途取得費用がかかるため、まずは無料の `pages.dev` URLで公開できます。

## アイコン画像

公式アイコンのPNGを circle-icon.png という名前でこのフォルダに置くと、ヘッダー・フッターとブラウザーのタブアイコンに表示されます。正方形のPNGがおすすめです。
