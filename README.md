# Re:Create テストサイト

https://re-create-test.a240868a.workers.dev/

阪本飛夏の作業アーカイブのために公開している、プログラミングサークル Re:Create のテストサイトです。


## 制作方法

- ChatGPT work をコーディング、ReadMe作成に使用しています。
- HTML・CSS・JavaScriptだけで作った静的サイトです。
- サーバー側のプログラムやデータベース、ビルド作業は必要ありません。
- `index.html` にページの構造と紹介文、`styles.css` に色・レイアウト・スマートフォン対応、`script.js` にメニュー操作やデータ表示を記述しています。
- 活動記録、年間スケジュール、掲載記事、サークル名、SNSリンクなどの更新データは `content.js` にまとめています。
- 外部ライブラリや有料サービスは使わずに動作します。フォントはGoogle Fontsから読み込むため、インターネット接続がない場合は端末の標準フォントで表示します。
- PC・スマートフォンの両方で読みやすいようにレイアウトを切り替えています。ヘッダーは画面上部、フッターは画面下部に固定しています。

## 内容の更新方法

1. `content.js` をテキストエディターで開きます。
2. 更新したい配列・項目を編集します。文章は `"` で囲み、項目どうしはカンマで区切ります。
3. 保存して `index.html` をブラウザーで開き、表示を確認します。

### よく更新する項目

- `name`: サークル名
- `instagram`、`x`: InstagramとXのプロフィールURL
- `activities`: 活動記録。日付、カテゴリー、タイトル、説明、アイコン、色を1件ずつ登録します。制作途中のものは「制作中」と明記します。
- `schedule`: 年間スケジュール。時期、タイトル、説明を登録します。年度によって時期が変わる場合は「目安」と分かる表現にします。
- `press`: メディア掲載記事。掲載日、媒体名、記事タイトル、記事URLを登録します。

各配列の項目を複製して、値を書き換えると新しい記録を追加できます。掲載を取りやめるときは、その項目を配列から削除します。

### ページの見た目や文章を変える場合

- ページの見出し、紹介文、ナビゲーションを変える: `index.html`
- 配色、余白、カード、スマートフォン表示を変える: `styles.css`
- メニューやデータの表示方法を変える: `script.js`
- ブラウザーのタブに表示されるタイトルや説明文を変える: `index.html` の `<title>` と `meta name="description"`

サークルのPNGアイコンを使う場合は、画像を `circle-icon.png` という名前でこのフォルダ直下に置きます。ヘッダー・フッターとブラウザーのタブアイコンに表示されます。正方形のPNGがおすすめです。

## 公開・更新方法

Cloudflare PagesとGitHubを使うと、GitHubに変更を反映したときにサイトを自動で再公開できます。

1. このフォルダ内のサイトファイルをGitHubリポジトリに追加します。
2. Cloudflare Pagesで新しいプロジェクトを作り、そのGitHubリポジトリを接続します。
3. ビルド設定はフレームワーク「None」、ビルドコマンドは空欄、出力ディレクトリは `/`（リポジトリ直下）にします。
4. 公開後は、変更したファイルをGitHubに反映すると自動で再デプロイされます。

公開前に `content.js` の活動・記事・SNSリンクが正しいことと、リンク先が公開可能な情報であることを確認してください。
